# «Сам себе банкротчик» — мини-приложение для MAX

Простая версия помощника по банкротству гражданина. Открывается прямо в мессенджере MAX.

## Что умеет

1. **Знакомство и согласия** — 3 коротких экрана (что умеет / чего не делает / где данные) и два отдельных
   согласия: соглашение с политикой и согласие на обработку данных. Тексты открываются прямо в приложении.
2. **Тест «Подхожу ли я?»** — 13 вопросов. Путь (МФЦ или суд), светофор рисков с объяснениями, последствия.
3. **Документы** — личный список по результатам теста: зачем, где и как получить, срок, цена.
   Статусы «нет / заказал / получил», предупреждение, когда справка устаревает, заметки, копирование списка.
4. **Анкета по шагам** — о вас, семья и доходы, имущество и счета, сделки, кредиторы, суд и заявление.
   Проверка ИНН, СНИЛС, паспорта, дат и сумм; суд определяется по адресу; черновик «как появились долги».
   Номер телефона можно подставить из MAX одной кнопкой. Для пути через МФЦ шагов меньше.
5. **Документы для подачи** — заявление в суд (ФИО склоняется по падежам и роду, сумма прописью,
   уполномоченный орган — УФНС региона), список кредиторов и опись имущества **по структуре форм
   приказа Минэкономразвития № 530** (все разделы, налоги отдельно), два ходатайства,
   письмо финуправляющему, данные для МФЦ. Перед выдачей — проверка полноты и самопроверка.
   В MAX текст копируется или отправляется себе в чат; в браузере — ещё Word и PDF.
6. **Этапы процедуры** — для суда и МФЦ, отметка «я здесь», вопрос по этапу.
7. **Вопросы и ответы** — поиск по базе со ссылками на закон, отказ в помощи со скрытием имущества,
   словарь терминов.
8. **Помощь юриста** — форма с согласием; сообщение юристам ООО «Арбитръ» отправляет сам пользователь.
9. **Настройки** — размер текста, удаление всех данных, документы сервиса.

Всё бесплатно. Данные человека хранятся только в его телефоне — сервера у мини-приложения нет.
Чтобы обновить суммы, сроки или тексты, достаточно заменить файлы в `data/` на хостинге — пересобирать ничего не нужно.

## Из чего состоит

| Файл | Что это |
|---|---|
| `index.html`, `styles.css`, `app.js` | Само приложение: экраны и оформление |
| `logic.js` | Правила: тест, список документов, проверка полей, составление документов, ответы на вопросы |
| `form-schema.js` | Шаги анкеты: какие поля и списки на каждом шаге |
| `storage.js` | Сохранение данных на телефоне |
| `data/*.json` | **База правил**: суммы, сроки, вопросы теста, документы, ответы, шаблоны, тексты соглашения и политики (`legal.json`). Меняется без программиста |
| `vendor/` | Готовые библиотеки: Mustache — шаблоны, «Петрович» — склонение ФИО (обе MIT) |

## Как запустить в MAX — по шагам

**1. Нужен статус.** В MAX подключаются только юрлица, ИП и самозанятые из России.

**2. Выложите папку в интернет.** Подойдёт любой хостинг с адресом `https://…`:
- **GitHub Pages** — бесплатно: создать репозиторий, загрузить файлы этой папки, включить Pages в настройках;
- **VK Cloud** — есть [специальный хостинг для мини-приложений MAX](https://cloud.vk.com/promopage/max-mini-app/);
- **Yandex Cloud** (Object Storage) — тоже подходит.

Загрузите **всё содержимое папки** (кроме `README.md` и `test.mjs` — они не нужны). Должен открываться адрес вида
`https://ваш-адрес/index.html`.

**3. Создайте бота в MAX.** Зайдите на платформу [MAX для партнёров](https://business.max.ru/self) →
«Чат-боты» → создайте бота.

**4. Подключите мини-приложение.** В настройках бота вставьте адрес из шага 2 и выберите кнопку
«Открыть». Сохраните — в чате с ботом появится кнопка запуска.

**5. Готово.** Ссылка, которой можно делиться: `https://max.ru/<имя_бота>?startapp`.

## Как опубликовать изменения

```bash
./release.sh "что изменилось"
```

Скрипт проверит логику, поставит новый номер версии (чтобы браузеры не смешивали старые и новые
файлы из кэша) и загрузит всё на GitHub Pages. Через 1–2 минуты изменения появятся на сайте.

## Как проверить на компьютере

```bash
python3 -m http.server 8095
```

и открыть `http://localhost:8095` в браузере. Вне MAX приложение работает так же, только данные
хранятся в браузере, а кнопка «Отправить себе в чат» заменяется на «Распечатать».

## Перед запуском обязательно

- **Юрист должен проверить** шаблоны заявлений (`data/templates.json`) и суммы в `data/rules.json` —
  сейчас это черновики, в тексте заявления стоит пометка об этом.
- Госпошлина в базе правил намеренно не заполнена — внести после проверки.
- Реквизиты оператора (ООО «Арбитръ») уже вписаны в `data/legal.json`. Дайте юристу вычитать соглашение,
  политику и согласие. У MAX на платформе есть типовые шаблоны — сверьтесь с ними.
- Если у ООО «Арбитръ» есть чат в MAX, впишите ссылку в `PARTNER.max` в начале `app.js` —
  тогда кнопка «Написать юристу» откроет этот чат.

## Заполнение кредитора по ИНН

Кнопка «Заполнить название и адрес по ИНН» появится, если вписать ключ DaData в `DADATA_TOKEN`
в начале `app.js` (бесплатный тариф: dadata.ru → регистрация → API-ключ). Сервису уходит только ИНН
кредитора-организации, данных пользователя нет.

## Чего пока нет (можно добавить позже)

- Оплаты — версия полностью бесплатная.
- ИИ-консультанта — сейчас ответы берутся из готовой базы вопросов.
- Скачивания файлов Word/PDF — в MAX файлы скачиваются только с сервера, поэтому заявление
  копируется текстом.
- Разбивки адреса на графы (район, город, улица, дом) в формах № 530 — сейчас субъект РФ
  и адрес полностью.
- Расчёта прожиточного минимума — нужны официальные данные по регионам.
- Напоминаний о сроках справок в виде уведомлений — для этого нужен бот с сервером.
